# געגע בקרקס המשוגע — אתר מלא

אתר תדמית + חנות + הזמנת הופעות + הגרלות + מערכת ניהול, למותג "געגע בקרקס המשוגע".

## איך זה בנוי (טכנולוגיה)

- **Frontend**: HTML / CSS / JavaScript רגיל (ללא build step, ללא צורך ב-Node) — כל דף נטען ישירות בדפדפן.
- **Backend + מסד נתונים**: [Supabase](https://supabase.com) — Postgres + Auth + API, בחינם.
- **אחסון וקוד**: GitHub.
- **פרסום לאוויר**: Vercel או Netlify (חינם, מתחבר ישירות ל-GitHub).
- **וואטסאפ**: קישור `wa.me` פשוט, בלי API בתשלום.

**עלות: 0 ₪.**

---

## שלב 1 — הקמת Supabase

1. הירשמו בחינם ב-[supabase.com](https://supabase.com) וצרו פרויקט חדש.
2. בתפריט השמאלי: **SQL Editor** → פתחו שאילתה חדשה → הדביקו את כל התוכן של הקובץ `sql/schema.sql` מהתיקייה הזו → **Run**.
   זה ייצור את כל הטבלאות, ה-RLS policies, וגם יכניס 4 מוצרי דוגמה + הגרלה פעילה אחת.
3. בתפריט **Project Settings → API**, העתיקו:
   - `Project URL`
   - `anon public` key
4. פתחו את הקובץ `js/config.js` והדביקו את הערכים במקום ה-placeholders.
5. צרו משתמש מנהל: **Authentication → Users → Add user** — הזינו אימייל וסיסמה. זה חשבון הכניסה למערכת הניהול (`admin.html`).

## שלב 3 — פרסום לאוויר (Vercel)

1. היכנסו ל-[vercel.com](https://vercel.com) עם חשבון GitHub.
2. **Add New Project** → בחרו את הריפו → **Deploy**.
   (אין צורך בהגדרות build — זה אתר סטטי טהור.)
3. תוך דקה תקבלו קישור חי לאתר.

> אפשר גם Netlify באותה שיטה בדיוק (גרירת התיקייה או חיבור ל-GitHub).

## שלב 4 — עדכון פרטי העסק

- `js/common.js` → עדכנו את `WHATSAPP_PHONE` למספר האמיתי (פורמט בינלאומי, למשל `972501234567`).
- אפשר להחליף את תמונות המוצרים וההגרלה ישירות בטבלת `products` / `raffles` ב-Supabase (**Table Editor**), על ידי הדבקת קישור לתמונה אמיתית בעמודת `image_url`.

## מה פתרתי ואיך

- **סליקה**: אין סליקה אמיתית כנדרש — טופס ה"רכישה" שומר את פרטי הקונה ישירות לטבלת `orders` ב-Supabase, והמנהל רואה ומעדכן סטטוס בלוח הניהול.
- **הרשאות**: השתמשתי ב-Row Level Security של Supabase — כל אחד יכול *לשלוח* טפסים (הזמנה/פנייה/הרשמה), אבל רק משתמש מחובר (המנהל) יכול *לקרוא* ולעדכן את הנתונים. כך לא צריך לבנות שרת/Backend בכלל.
- **וואטסאפ**: אחרי שליחת טופס ההופעה, מוצג למשתמש קישור `wa.me` עם טקסט מוכן מראש הכולל את הפרטים שהזין, בהתאם לדרישה "בסיום ממשיכים ל-WhatsApp".
- **ניהול הגרלה**: בלוח הניהול, לכל הגרלה מוצגת רשימת הנרשמים עם כפתור "בחר/י כזוכה" שמסמן זוכה בטבלת ה-DB.
- **0 ₪**: כל הכלים בפרויקט (Supabase, GitHub, Vercel/Netlify) הם בעלי tier חינמי מלא שמספיק בענק לפרויקט בגודל הזה.

## מגבלות ידועות (לשקיפות)

- ניהול המוצרים עצמם (הוספה/עריכה) נעשה כרגע ישירות דרך Table Editor של Supabase ולא דרך ממשק ניהול ייעודי — כדי להתמקד בזמן הנתון בזרימות שהוגדרו כחובה (הזמנות, פניות, הגרלות).
- תמונות המוצרים הן placeholder — יש להחליף לתמונות אמיתיות לפני שימוש מלא.
